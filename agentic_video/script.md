# 具身智能体（Agentic Robotics）讲解视频 · 分镜与解说词

基于仓库：https://github.com/w-xb/awesome-agentic-robotics
预计时长：约 6 分钟，共 17 幕

## S1 封面
**画面**：标题页 —— 具身智能体 Agentic Robotics
**解说**：大家好。这期视频我们讲解"具身智能体"，英文叫 Agentic Robotics。内容基于 GitHub 上的精选论文清单 Awesome Agentic Robotics，它系统梳理了这个新兴方向的核心概念、技术栈和代表工作。

## S2 什么是 Agentic Robotics
**画面**：能力中心定义要点
**解说**：仓库采用能力中心的定义：一个机器人系统越能感知并维持任务状态、利用记忆、对未来后果进行规划、调用技能和工具、验证执行结果、从失败中恢复，并在物理安全约束下行动，它就越具有智能体性。所以具身智能不是非黑即白的标签，而是一条连续谱。

## S3 与软件 Agent 的区别
**画面**：对比要点
**解说**：和纯软件智能体不同，软件智能体的规划、记忆和反思大多通过文本和 API 完成；而机器人必须在动态、部分可观测的物理世界中行动。因此它的智能不仅依赖外部的大模型循环，还依赖具身机制：时空记忆、动作条件的世界模型、落地的技能接口、执行监控、失败归因、恢复策略和安全包络。

## S4 核心架构：Agent–Harness–VLA 闭环栈
**画面**：分层栈示意图
**解说**：仓库的组织视角是一个三层闭环栈。最上层是 Agent 规划器，负责推理、任务分解和维护任务状态；中间是 Harness 运行时，负责记忆、工具、路由、验证、恢复和安全；最下面是 VLA 策略，把感知直接映射为物理动作；物理世界返回观测、结果和失败。被验证过的持久化更新跨回合积累，就形成了自我进化。

## S5 三层各管什么
**画面**：三层职责
**解说**：这个栈的价值在于分清三个常被混为一谈的问题：Agent 回答接下来做什么、为什么；Harness 回答组件如何被协调、检查、重试、恢复和约束；VLA 回答多模态上下文如何变成可执行的物理动作。

## S6 能力地图：八个能力层
**画面**：8 层表格（两列）
**解说**：在这个栈之上，清单进一步划分出八个能力层：规划器、运行时、记忆、世界模型、策略、技能工具、验证安全，以及物理世界与评测。每一层都对应一组研究问题，也对应一种可以被持久改进的进化目标。

## S7 规划与推理
**画面**：代表工作列表
**解说**：规划方向从 2022 年的 SayCan 开始确立范式：用语言模型产出候选技能，再用学到的可供性给物理可行性打分。Inner Monologue 把环境反馈、成功检测和重规划接进循环。之后的 ProgPrompt 把计划写成带断言和恢复步骤的程序，VoxPoser 生成三维价值图，ThinkAct 则在视觉潜空间里做强化规划。

## S8 具身记忆
**画面**：代表工作列表
**解说**：长时程任务最大的敌人是遗忘。AtlasVLA 维护持久的世界-自我状态来追踪空间上下文和任务进度；MemoryVLA 把感知记忆和认知记忆同时接入控制；MEM 构建多尺度记忆；3D-Mem 和 DynaMem 维护显式的空间语义场景记忆；MEMORA 则把第一人称视频经验提炼成可检索、可编辑的动作记忆。

## S9 世界模型
**画面**：代表工作列表
**解说**：世界模型让机器人能在行动前先想象后果。V-JEPA 2 用大规模自监督视频学习预测表征；τ_0-WM 把动作生成、未来视频预测、候选评估和仿真校正统一在一个模型里；世界-动作模型 WAM 正在成为独立方向；PointWorld 把预测扩展到三维点云空间。

## S10 Agentic VLA
**画面**：代表工作列表
**解说**：VLA 本身也在智能体化。π0.5 用异构协同训练实现开放世界泛化；Gemini Robotics 1.5 把显式思考和跨本体动作迁移放进通用策略；Hi Robot 做分层指令拆解；Harness VLA 把冻结的 VLA 包装成可重试的操作原语，由上层智能体负责验证和恢复；Agentic Robot 则提出经典的计划-执行-验证三环结构。

## S11 验证与安全
**画面**：代表工作列表
**解说**：可靠性的另一半是验证。从用通用视觉语言模型做成功检测，到 Pre-VLA 在动作执行前做预防性验证，再到 MANIGUARD 对操作过程而不是最终结果做安全评测。治理方向甚至开始研究具身多智能体系统中的同意链退化和运行时政策约束。

## S12 失败检测与恢复
**画面**：代表工作列表
**解说**：失败不可避免，关键是闭环处理。SAFE 训练跨任务共享的失败检测器；FPC-VLA 加一个监督模型在错误传播之前纠偏；FailSafe-VLM 能解释失败原因并生成恢复策略；CycleVLA 主动识别不确定的子任务并回溯重选动作。

## S13 技能学习与工具使用
**画面**：代表工作列表
**解说**：技能和工具是智能体能力的落脚点。Code as Policies 让语言模型直接生成组合感知和控制接口的策略代码；DeCo 通过任务分解和技能组合实现零样本泛化；还有工作让视觉语言模型选择并使用没见过的物理工具；ROS-LLM 和 RAI 则提供接进 ROS 的工程框架。

## S14 自我进化
**画面**：判据 + 六大进化目标
**解说**：自我进化是这份清单最有特色的部分。判据很严格：一次改动必须经过验证、持久保留、并且影响后续回合，才算进化；回合内的重规划和重试只算瞬时适应。进化目标分六类：运行时、技能库、验证契约、策略数据、奖励目标和记忆上下文。Zetta 冻结基座模型只进化运行时组件；Eureka 进化奖励函数；RoboCat 是最早的真机策略自我改进案例。

## S15 长时程、导航与基准
**画面**：要点列表
**解说**：应用侧，长时程操作靠进度建模和技能链接维持任务状态；导航方向把空间记忆和零样本视觉语言导航结合。支撑这一切的是评测基础设施：LIBERO 测终身学习，CALVIN 测长链条操作，RoboCasa365 提供大规模仿真日常任务，Open X-Embodiment 奠定了跨本体数据基础。

## S16 怎么用这份清单
**画面**：阅读路线
**解说**：使用建议：清单开头给出五条阅读路线共二十五篇高信号论文，按 VLA 即工具、自我进化、分层推理、记忆世界模型、规划安全评测分组。每篇论文只按主要贡献归类一次，次要能力写在描述里；被策展淘汰的工作保留在 Extended Reading 中。

## S17 总结
**画面**：三条结论 + 仓库地址
**解说**：总结三点：第一，具身智能是连续谱，单个组件的突破和完整的闭环系统都在这张地图上。第二，可靠的长时程自主性越来越取决于推理、记忆、世界模型、技能、验证、恢复、安全和底层控制如何作为一个闭环协同，而不只是把 VLA 做得更大。第三，一个重要的开放方向是跨层协同进化，让各层联合进化，同时保持兼容、安全和稳定的物理行为。仓库地址在屏幕上，感谢观看。
